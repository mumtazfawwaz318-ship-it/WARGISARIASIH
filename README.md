# Wargi Hub
Landing page mobile-first untuk Sate Maranggi Wargi Sari Asih.

## Run lokal
npm install
npm run dev

## Deploy
Push folder ini ke GitHub, lalu Import Project di Vercel. Framework akan terdeteksi sebagai Next.js.

## Sebelum live
Ganti semua href="#" di `app/page.js` dengan link asli: Google Maps tiap outlet, WhatsApp, menu, GoFood/GrabFood/ShopeeFood, feedback form, Google Review, Instagram dan TikTok.

## Visual
Font: Montserrat via next/font/google.
Palet: red / warm cream / black.
